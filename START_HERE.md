## 🚨 Troubleshooting

### "Cannot connect to localhost:5000"
- Make sure backend is running: `npm run dev:backend`
- Check that port 5000 is free

### "Cannot get /api/assets"
- Backend is not running
- Make sure both processes are running
- Check terminal for errors

### "Images not uploading"
- Check browser console (F12) for errors
- Verify file is a valid image (JPG, PNG, etc.)
- Check network tab for failed requests

### "Port already in use"
- Stop other Node processes
- Or use different port in .env

**Still stuck?** Check SETUP.md troubleshooting section!
